# MarinResource
## Liste des permissions utilisées

| Permission                              | Description / Fonctionnalité                                                                                   |
|------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| fcmcentral::voir_tous_les_marins         | Permet de voir tous les marins dans la navigation et la liste.                                                 |
| fcmcentral::exporter_csv                 | Permet d’exporter la liste des marins au format CSV.                                                           |
| fcmcentral::attribuer.cohorte            | Permet d’attribuer une cohorte à un marin (activation FCM, gestion de cohorte).                                |
| fcmcentral::attribuer.mentor             | Permet d’attribuer un mentor à un marin (activation FCM, gestion de mentor).                                   |
| fcmcentral::attribuer.parcours           | Permet d’attribuer un parcours à un marin (activation FCM, gestion de parcours).                               |
| fcmcentral::definir_jalons_de_fcm        | Permet de modifier les jalons FCM d’un marin (dates de sédimentation, FCM, compétence).                        |
| fcmcentral::livret.voir                  | Permet de voir le livret FCM d’un marin.                                                                       |
| fcmcentral::livret.telecharger           | Permet de télécharger le livret FCM au format PDF.                                                             |
| fcmcentral::note.creer                   | Permet de créer une note pour un marin suivi en FCM.                                                           |
| fcmcentral::note.valider                 | Permet de valider une note BCF lors de la création de note.                                                    |
